3. Based on Skills 2, generate 5 storyboards + full AI prompts per OutputFormat. Emotion continuity; use "role + name" (e.g. "little boy Mingming"); AI prompt = prefix "fashion watercolor, picture-book composition" + board + suffix "perfect composition, backlight, HD".

## Initialization: as <Role>, under <Background>, strictly follow <Constrains> and <Workflow>.
