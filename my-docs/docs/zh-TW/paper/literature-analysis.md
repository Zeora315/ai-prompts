# 文獻分析全流程指令

一份用於「文獻分析全流程」的 AI 提示詞，適用於論文寫作與學術研究。將提示詞粘貼到下方代碼框，複製後發給 AI 即可使用。



## 提示詞

```text
我需要你推薦【數字】篇【研究方向】相關的文獻，文獻要求為近【數字】年發表，按照標
題、作者、發表年份、摘要、原文鏈接的格式回覆我。
文獻總結指令（加粗處根據自己需求來修改）
我現在需要分別給上述【數字】篇文獻，列出該文獻的標題、作者、發表年份、文獻摘要、
研究目標、研究背景、研究方法、研究價值、研究不足。你每次回覆我，只給出一篇文獻的
上述信息。直到我要求繼續後，你再依次給出下一篇文獻的關鍵信息。現在請開始給出第一
篇文獻的關鍵信息。
追加文獻指令：
我需要你再推薦【數字】篇【研究方向】相關的文獻，文獻要求為近 5 年發表，按照標題、
作者、發表年份、摘要、原文鏈接的格式回覆我。新推薦的 20 篇文獻要與上述推薦的文獻
沒有重複。追加文獻指令
文獻對比指令： 
 用途：用於對不同文獻中的觀點進行對比分析。 
 指令： 
 請將之前推薦的【數字】篇文獻進行對比，按照以下維度進行分析：研究目標的異同、
研究方法的異同、結論的異同、研究侷限性與未來研究方向的異同。每個維度請單獨列出詳
細的對比內容。
文獻引用格式整理指令： 
 用途：用於將多篇文獻按特定引用格式輸出，方便寫作時使用。 
 指令： 
 請將之前推薦的【數字】篇文獻，按照【格式名稱】的引用格式（如 APA、MLA、Chicago
等）整理並輸出。每篇文獻的信息應包括：作者、發表年份、標題、期刊名稱、期卷號、頁
碼、DOI 或 URL。
文獻研究趨勢總結指令： 
 用途：用於總結某個研究領域的最新發展趨勢。 
 指令： 
 請根據之前推薦的【數字】篇文獻，提取並總結出當前【研究方向】領域的主要研究趨
勢、熱點問題和未來研究方向。每個趨勢或問題請給出支持文獻的具體引用。
文獻圖表整理指令： 
 用途：用於提取文獻中的圖表信息，幫助可視化數據。 
 指令： 
 請從之前推薦的【數字】篇文獻中，提取所有涉及的圖表信息，包括圖表類型（如圖形、
表格）、圖表的研究目的、數據來源及結論。請用列表形式展示每篇文獻的圖表信息，並總
結其數據的關鍵意義。
文獻引用率與影響力分析指令： 
 用途：用於分析文獻的引用次數和學術影響力。 
 指令： 
 請對之前推薦的【數字】篇文獻的引用率和影響力進行分析，按照每篇文獻的引用次數、
H 指數及影響因子進行排序，並給出分析結論。這將有助於我瞭解哪些文獻在該領域中具有
較高的學術影響力。
```


## 使用建議

- 將上方提示詞完整複製後發給 AI 即可使用。
- 如提示詞中含 [ ] 佔位或示例，替換為你自己的內容。
- 若輸出不滿意，補充風格、長度、平臺等偏好讓其迭代優化。
