# 文獻綜述 24 條指令

一份用於「文獻綜述」的 AI 提示詞（共 24 條），適用於論文寫作與學術研究。將提示詞粘貼到下方代碼框，複製後發給 AI 即可使用。



## 提示詞

```text
1.我現在需要撰寫一篇研究主題為【你的研究主題】。要求你啟動瀏覽功能尋找發表時間為
【發表年份】年之後，並且引用次數最多的【數量】篇相關文獻。你的回覆格式為標題、作
者、發表年份、引用次數、查看鏈接。
2.我需要你對上述【數量】篇文獻，分別進行文獻綜述。並給出每篇文獻的簡要、研究方法、
研究結論、研究不足及改進、論文優劣。
3.將上面的【數量】篇文獻的簡要綜述，整合為一個具有學術規範的文獻綜述段落，需要注
意上下文的邏輯，並且在對應的位置插入引用文獻，嚴格按照 AMA 格式插入並給出參考文
獻列表。
4. 我需要你針對我上傳的【數量】篇文獻，分別進行文獻綜述
擴展：以下是更加詳細、全面、準確的 20 條提示（prompt），旨在協助你在文獻綜述的
各個環節進行深入分析和寫作：
1. 全面的關鍵詞提取與主題定位
 - 請從 【文獻名稱】 中提取所有相關的關鍵詞和主題詞，包括主要研究領域、核心概
念、方法論和任何特定的技術術語，以幫助明確該研究的焦點和範圍。
2. 深入的研究背景與動機分析
 - 詳細闡述 【文獻名稱】 的研究背景，包括該領域的發展歷史、現有研究的不足之處、
當前存在的知識空白，以及作者進行該研究的動機和目的。
3. 詳盡的理論框架與模型解析
 - 請解釋 【文獻名稱】 所採用的理論框架或模型，詳細描述其組成部分、原理和適用
範圍，並討論其如何支持研究問題的提出和假設的形成。
4. 明確的研究問題和假設陳述
 - 列出並解釋 【文獻名稱】 中提出的具體研究問題和假設，包括每個假設的理論依據
和其在研究中的作用。
5. 嚴謹的研究方法與設計評估
 - 深入分析 【文獻名稱】 的研究方法，包括研究類型（如定性、定量或混合方法）、
研究設計（如實驗設計、調查研究）、數據收集方法（如問卷、訪談、觀察）和樣本選擇標
準，並評價其適用性和可能的侷限性。
6. 數據分析技術和工具的深入探討
 - 詳細描述 【文獻名稱】 中使用的數據分析技術，包括統計分析方法、模型構建、軟
件工具（如 SPSS、R、NVivo）等，並討論這些方法如何支持研究結果的可靠性和有效性。
7. 結果的全面解釋與意義闡釋
 - 對 【文獻名稱】 的研究結果進行深入的解釋，討論主要發現、統計顯著性、與假設
的關係，以及這些結果在理論和實踐上的意義。
8. 與現有文獻的比較與討論
 - 將 【文獻名稱】 的結果與其他相關研究進行比較，討論一致性或差異，分析可能的
原因，並闡述該研究對現有知識體系的貢獻或挑戰。
9. 研究侷限性和改進建議的深入分析
 - 詳細分析 【文獻名稱】 中提到的研究侷限性，包括樣本規模、方法限制、數據來源
等，並提出針對這些侷限性的具體改進建議。
10. 結論的綜合評述與實踐啟示
 - 總結 【文獻名稱】 的主要結論，討論其對實際應用的啟示或建議，以及對政策制定、
行業實踐或未來研究的影響。
11. 文獻的學術影響力和作者權威性評估
 - 評估 【文獻名稱】 的學術影響力，包括髮表的期刊影響因子、引用次數、作者在該
領域的聲譽和貢獻，以及這對文獻可信度的影響。
12. 引用文獻的質量和相關性分析
 - 審查 【文獻名稱】 中引用的關鍵文獻，評估其質量、相關性和新穎性，分析這些引
用如何支持作者的論點和研究框架。
13. 跨文獻的理論和方法比較研究
 - 比較 【文獻 1 名稱】、【文獻 2 名稱】 和 【文獻 3 名稱】 的理論基礎和研究方法，
討論它們在研究問題、假設、方法論和結果上的異同點。
14. 領域研究趨勢和熱點問題綜述
 - 綜合 【數量】 篇文獻，提煉該領域的研究趨勢和熱點問題，討論當前關注的主題、
主要爭議點和未來可能的發展方向。
15. 定量結果的元分析
 - 如果適用，請對 【數量】 篇文獻的定量研究結果進行元分析，計算綜合效應量，評
估總體趨勢，並討論異質性的來源。
16. 研究對實踐的影響和案例分析
 - 分析 【文獻名稱】 的研究如何影響實際操作或政策制定，提供具體的案例或情景，
說明研究結果的應用方式和效果。
17. 倫理考慮和合規性評估
 - 評估 【文獻名稱】 中的倫理考慮，包括研究是否經過倫理審查、如何保護參與者的
權益、數據隱私和知情同意等方面的措施。
18. 研究的創新性和原創性評估
 - 討論 【文獻名稱】 的創新之處，包括新發現、新方法、新理論或新應用，評估其對
推動該領域發展的貢獻。
19. 文獻寫作風格和邏輯結構分析
 - 分析 【文獻名稱】 的寫作風格、語言清晰度、邏輯結構和論證方式，討論這些因素
對讀者理解和研究傳播的影響。
20. 高質量文獻綜述的撰寫策略和建議
 - 基於對 【數量】 篇文獻的分析，提供詳細的撰寫高質量文獻綜述的策略，包括選題
範圍界定、文獻篩選標準、結構組織、批判性分析和引用規範等方面的具體建議。
```


## 使用建議

- 將上方提示詞完整複製後發給 AI 即可使用。
- 如提示詞中含 [ ] 佔位或示例，替換為你自己的內容。
- 若輸出不滿意，補充風格、長度、平臺等偏好讓其迭代優化。
