## 11. 使用Tips：搭配本站提示詞增效方案
1. **長文檔場景（論文/財報/合同）**
   推薦工具：Kimi / Claude / 智譜清言
   配套提示詞：「論文 Kimchat 指令模型手冊」「合同深度風險審查指令」
2. **日常辦公寫作（週報/方案/短視頻腳本）**
   推薦工具：豆包 / 通義千問 / 火山寫作
   配套提示詞：「週報編寫助手」「短視頻爆款腳本生成指令」
3. **代碼開發**
   推薦工具：Cursor / Trae / DeepSeek
   配套提示詞：「全棧項目重構指令」「Bug定位修復專用提示詞」
4. **圖像視頻創作**
   推薦工具：Midjourney / 可靈 / 即夢
   配套提示詞：「國風插畫標準提示詞模板」「電影級視頻運鏡指令」
5. **學術研究**
   推薦工具：Gemini / Perplexity / 星火科研助手
   配套提示詞：「文獻綜述自動梳理指令」「實驗數據分析模板」
