# AI 漫劇人物提示詞通用公式模板

適用於 AI 漫劇、插畫等人物形象生成的通用提示詞公式，按分層維度逐項填寫即可產出高質量、低崩壞的人物提示詞。全平臺通用，可按需適配不同 AI 繪圖工具。

## 核心通用公式

```text
【核心定位】+【外貌細節】+【性格氣質+神態】+【漫劇風格】+【畫面參數】+【動作/場景適配】
```

## 提示詞分層填寫規範

| 分層維度 | 核心作用 | 填寫要點 | 示例填寫 |
|----------|----------|----------|----------|
| 基礎定位層 | 明確角色核心身份與人設，為 AI 建立角色基礎認知 | 年齡 + 身份/職業 + 核心人設標籤（性格/劇情屬性） | 19 歲女大學生 + 元氣社團社長 + 陽光開朗、熱心腸 |
| 細節描述層 | 補充角色外貌、穿搭、神態細節，避免形象模糊 | 1. 外貌：五官類型 + 髮型髮色 + 膚色/體型；2. 穿搭：風格 + 款式 + 材質 + 配飾；3. 神態：表情 + 眼神 + 氛圍感 | 杏眼、淺棕長卷發、冷白皮；淺藍碎花連衣裙 + 珍珠耳飾；笑眼彎彎、自帶柔光感 |
| 風格指令層 | 定義畫面質感與藝術風格，確保生成效果符合預期調性 | 畫風類型 + 線條特點 + 色調風格 | 日系二次元賽璐璐畫風 + 線條流暢柔和 + 暖色調（粉白 + 淺藍） |
| 技術參數層 | 保障生成質量，規避 AI 常見崩壞問題（如五官畸形、細節模糊） | 分辨率 + 畫面比例 + 細節要求 + 避坑指令 | 8K 高清 + 16:9 漫劇分鏡比例 + 面部細節精細、衣褶清晰 + 五官對稱、無雜亂背景 |
| 動作/場景適配層 | 適配漫劇分鏡、短視頻、插畫等具體使用場景，方便後續動態延展 | 基礎動作 + 適配場景（可選） | 單手托腮看書 + 適配校園圖書館場景 |
| 工具適配補充 | 針對特定 AI 工具優化，提升生成精準度 | 工具專屬關鍵詞（如 Lora 模型、風格預設） | Stable Diffusion：Lora:校園甜妹:0.8；醒圖 AI：簡化細節描述，突出核心風格 |

## 使用建議

- 按公式順序將各層內容拼接為一段完整提示詞，發給 AI 繪圖工具即可。
- 各層可自由組合複用：想換風格只改「風格指令層」，想換場景只改「動作/場景適配層」。
- 技術參數層的"避坑指令"建議保留，可顯著減少五官畸形、細節模糊等 AI 常見問題。
- 不同工具（Stable Diffusion / 醒圖 AI / Midjourney / 即夢等）可按「工具適配補充」針對性優化關鍵詞。
