# PPT生成指令

一份用於「PPT生成指令」的 AI 提示詞，適用於內容創作場景。複製下方提示詞發給 AI，並按需補充你的具體要求即可。

## 提示詞

```text
PPT 生成指令
##目的
本指令旨在引導用戶從提供的 PDF 文檔中提取關鍵信息，並以總-分-總的形式重點歸納和提
煉，製作成不少於 5 頁的演示 PPT。
## 操作步驟
### 第一步：分析和理解 PDF 文檔
1.確定 PDF 文檔的“主題”。
2.瀏覽”目錄”，，識別主要**章節**和相關的“內頁”、以便理解文檔結構。
###第二步：內容提煉
1.對於每個章節，提取至少 3 個關鍵點，每個關鍵點都需用序號標明。
2.為每個關鍵點編寫簡短的“詳細觀點描述”，以確保內容的清晰和準確性。
### 第三步：PPT 製作
*每一頁 PPT*應圍繞一個清晰的觀點進行設計。
每一頁的內容應包括：
1.“章節”-表明該觀點來源於文檔的哪個部分。
2.“詳細觀點描述”-列出與該觀點相關的至少 3 個細節。
每一頁還應包含一個引發思考的內容，鼓勵觀眾深入思考所呈現的信息。
###第四步：總結
1.PPT 的最後部分應包括對全文核心觀點的總結。
2.以序號形式分條列出主要觀點，以幫助觀眾加深埋解和記憶。
## 注意事項
這個指令比較詳細，在提煉和製作 PPT 時，避免過於簡化。注意 PPT 的視覺設計，使用適
當的圖表、圖片和佈局來增強信息的表達和吸引力。考慮到觀眾的多樣性，確保 PPT 內容
的通俗易懂，儘量避免使用過於專業或複雜的術語。
##輸出形式
用 markdown 的格式輸出。
現在請提示我發送 pdf 文檔給你吧
```

## 使用建議

- 將上方提示詞完整複製後發給 AI 即可使用。
- 如提示詞中含 `[ ]` 佔位或示例，替換為你自己的內容。
- 若輸出不滿意，補充風格、長度、平臺等偏好讓其迭代優化。
