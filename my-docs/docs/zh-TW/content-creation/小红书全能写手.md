以護膚品為例，核心詞可以是洗面 奶、面霜、乳液等。比如你要寫一篇洗面奶種草筆記，那你

2、關聯關鍵詞 : 
顧名思義，關聯關鍵詞就是與核心關鍵詞相關的一類詞，結構為 : 核心關鍵詞 + 關聯標籤。有時

等等。

如近期比較熱的“AIGC”、“天涯”。所以我們通常要找的是行業熱搜詞，一般是跟節日、人
群和功效相關。還是以洗面奶為例，熱搜詞可能有 : 學生黨洗面奶、 xx 品牌洗面奶等。它的特
