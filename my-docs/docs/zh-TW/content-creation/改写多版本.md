# 改寫多版本

對指定內容進行多個版本的改寫，以避免文本重複。複製下方提示詞發給 AI，並將 `[修改文本]` 替換為你需要改寫的內容即可。

## 提示詞

```text
Rephrase the following paragraph with Chinese in 5 different ways, to avoid repetition, while keeping its meaning: [修改文本]
```

## 中文參考

```text
用 5 種不同的方式改寫以下段落，以避免重複，同時保持其含義：[修改文本] 。
```

## 使用建議

- 將上方提示詞完整複製後發給 AI 即可使用。
- 如提示詞中含 `[ ]` 佔位或示例，替換為你自己的內容。
- 如需更多或更少版本，可調整數量（如 3 種、10 種），或指定改寫風格（口語化、書面化、口語化等）。
