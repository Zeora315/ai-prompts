# 重寫提示詞

讓 ChatGPT 為我們重新撰寫提示詞。由於人工書寫的提示詞邏輯與機器不同，重新修改提示語可令 ChatGPT 更容易理解。複製下方提示詞發給 AI，並將 `你的提示詞` 替換為你自己的提示詞即可。

## 提示詞

```text
I am trying to get good results from GPT-5 on the following prompt: '你的提示詞.' Could you write a better prompt that is more optimal for GPT-5 and would produce better results?
```

## 中文參考

```text
我正在嘗試從以下提示詞中獲得 GPT-5 的良好結果：你的提示詞。你能否寫出更優化、能夠產生更好結果的提示詞？
```

## 使用建議

- 將上方提示詞完整複製後發給 AI 即可使用。
- 如提示詞中含 `[ ]` 佔位或示例，替換為你自己的內容。
- 除 GPT-5 外，也可將模型名替換為實際使用的模型，讓優化結果更貼合目標模型。
