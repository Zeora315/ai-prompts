# 快速上手

歡迎使用 **AI 提示詞集**！這裡彙總了精選的 AI 提示詞，按「工作與效率 / 內容創作 / 學術與專業 / 其他」分類，幫你更高效地驅動 AI。

## 三步使用一條提示詞

1. **複製**：進入對應分類，點擊提示詞代碼塊右上角的複製按鈕。
2. **替換佔位符**：將文中的 `{{...}}`（如 `{{會議記錄}}`、`{{主題}}`）替換為你的真實內容。
3. **粘貼發送**：把填好的提示詞粘貼到任意 AI 對話工具（如 ChatGPT、Claude、通義千問等），發送即可。

:::tip
佔位符 `{{...}}` 只是示意，你可以保留、刪除或改寫它們，按自己的需要自由調整措辭與要求。
:::

## 使用技巧

- **明確角色與輸出格式**：提示詞裡已默認指定角色（如「資深執行官助理」）和格式（列表 / 表格），效果通常更好。
- **追加約束**：在提示詞末尾補充要求，例如「用表格輸出」「控制在 100 字以內」「面向小白解釋」。
- **多輪迭代**：第一版不滿意時，讓 AI「換一種風格再寫一版」或「更專業一些」，逐步逼近理想結果。
- **保存常用組合**：把高頻提示詞收藏到自己的筆記，形成個人提示詞庫。
