# AI 漫剧人物提示词通用公式模板

适用于 AI 漫剧、插画等人物形象生成的通用提示词公式，按分层维度逐项填写即可产出高质量、低崩坏的人物提示词。全平台通用，可按需适配不同 AI 绘图工具。

## 核心通用公式

```text
【核心定位】+【外貌细节】+【性格气质+神态】+【漫剧风格】+【画面参数】+【动作/场景适配】
```

## 提示词分层填写规范

| 分层维度 | 核心作用 | 填写要点 | 示例填写 |
|----------|----------|----------|----------|
| 基础定位层 | 明确角色核心身份与人设，为 AI 建立角色基础认知 | 年龄 + 身份/职业 + 核心人设标签（性格/剧情属性） | 19 岁女大学生 + 元气社团社长 + 阳光开朗、热心肠 |
| 细节描述层 | 补充角色外貌、穿搭、神态细节，避免形象模糊 | 1. 外貌：五官类型 + 发型发色 + 肤色/体型；2. 穿搭：风格 + 款式 + 材质 + 配饰；3. 神态：表情 + 眼神 + 氛围感 | 杏眼、浅棕长卷发、冷白皮；浅蓝碎花连衣裙 + 珍珠耳饰；笑眼弯弯、自带柔光感 |
| 风格指令层 | 定义画面质感与艺术风格，确保生成效果符合预期调性 | 画风类型 + 线条特点 + 色调风格 | 日系二次元赛璐璐画风 + 线条流畅柔和 + 暖色调（粉白 + 浅蓝） |
| 技术参数层 | 保障生成质量，规避 AI 常见崩坏问题（如五官畸形、细节模糊） | 分辨率 + 画面比例 + 细节要求 + 避坑指令 | 8K 高清 + 16:9 漫剧分镜比例 + 面部细节精细、衣褶清晰 + 五官对称、无杂乱背景 |
| 动作/场景适配层 | 适配漫剧分镜、短视频、插画等具体使用场景，方便后续动态延展 | 基础动作 + 适配场景（可选） | 单手托腮看书 + 适配校园图书馆场景 |
| 工具适配补充 | 针对特定 AI 工具优化，提升生成精准度 | 工具专属关键词（如 Lora 模型、风格预设） | Stable Diffusion：Lora:校园甜妹:0.8；醒图 AI：简化细节描述，突出核心风格 |

## 使用建议

- 按公式顺序将各层内容拼接为一段完整提示词，发给 AI 绘图工具即可。
- 各层可自由组合复用：想换风格只改「风格指令层」，想换场景只改「动作/场景适配层」。
- 技术参数层的"避坑指令"建议保留，可显著减少五官畸形、细节模糊等 AI 常见问题。
- 不同工具（Stable Diffusion / 醒图 AI / Midjourney / 即梦等）可按「工具适配补充」针对性优化关键词。
