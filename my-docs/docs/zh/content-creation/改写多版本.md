# 改写多版本

对指定内容进行多个版本的改写，以避免文本重复。复制下方提示词发给 AI，并将 `[修改文本]` 替换为你需要改写的内容即可。

## 提示词

```text
Rephrase the following paragraph with Chinese in 5 different ways, to avoid repetition, while keeping its meaning: [修改文本]
```

## 中文参考

```text
用 5 种不同的方式改写以下段落，以避免重复，同时保持其含义：[修改文本] 。
```

## 使用建议

- 将上方提示词完整复制后发给 AI 即可使用。
- 如提示词中含 `[ ]` 占位或示例，替换为你自己的内容。
- 如需更多或更少版本，可调整数量（如 3 种、10 种），或指定改写风格（口语化、书面化、口语化等）。
