# 重写提示词

让 ChatGPT 为我们重新撰写提示词。由于人工书写的提示词逻辑与机器不同，重新修改提示语可令 ChatGPT 更容易理解。复制下方提示词发给 AI，并将 `你的提示词` 替换为你自己的提示词即可。

## 提示词

```text
I am trying to get good results from GPT-5 on the following prompt: '你的提示词.' Could you write a better prompt that is more optimal for GPT-5 and would produce better results?
```

## 中文参考

```text
我正在尝试从以下提示词中获得 GPT-5 的良好结果：你的提示词。你能否写出更优化、能够产生更好结果的提示词？
```

## 使用建议

- 将上方提示词完整复制后发给 AI 即可使用。
- 如提示词中含 `[ ]` 占位或示例，替换为你自己的内容。
- 除 GPT-5 外，也可将模型名替换为实际使用的模型，让优化结果更贴合目标模型。
