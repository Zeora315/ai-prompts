# 文献分析全流程指令

一份用于「文献分析全流程」的 AI 提示词，适用于论文写作与学术研究。将提示词粘贴到下方代码框，复制后发给 AI 即可使用。



## 提示词

```text
我需要你推荐【数字】篇【研究方向】相关的文献，文献要求为近【数字】年发表，按照标
题、作者、发表年份、摘要、原文链接的格式回复我。
文献总结指令（加粗处根据自己需求来修改）
我现在需要分别给上述【数字】篇文献，列出该文献的标题、作者、发表年份、文献摘要、
研究目标、研究背景、研究方法、研究价值、研究不足。你每次回复我，只给出一篇文献的
上述信息。直到我要求继续后，你再依次给出下一篇文献的关键信息。现在请开始给出第一
篇文献的关键信息。
追加文献指令：
我需要你再推荐【数字】篇【研究方向】相关的文献，文献要求为近 5 年发表，按照标题、
作者、发表年份、摘要、原文链接的格式回复我。新推荐的 20 篇文献要与上述推荐的文献
没有重复。追加文献指令
文献对比指令： 
 用途：用于对不同文献中的观点进行对比分析。 
 指令： 
 请将之前推荐的【数字】篇文献进行对比，按照以下维度进行分析：研究目标的异同、
研究方法的异同、结论的异同、研究局限性与未来研究方向的异同。每个维度请单独列出详
细的对比内容。
文献引用格式整理指令： 
 用途：用于将多篇文献按特定引用格式输出，方便写作时使用。 
 指令： 
 请将之前推荐的【数字】篇文献，按照【格式名称】的引用格式（如 APA、MLA、Chicago
等）整理并输出。每篇文献的信息应包括：作者、发表年份、标题、期刊名称、期卷号、页
码、DOI 或 URL。
文献研究趋势总结指令： 
 用途：用于总结某个研究领域的最新发展趋势。 
 指令： 
 请根据之前推荐的【数字】篇文献，提取并总结出当前【研究方向】领域的主要研究趋
势、热点问题和未来研究方向。每个趋势或问题请给出支持文献的具体引用。
文献图表整理指令： 
 用途：用于提取文献中的图表信息，帮助可视化数据。 
 指令： 
 请从之前推荐的【数字】篇文献中，提取所有涉及的图表信息，包括图表类型（如图形、
表格）、图表的研究目的、数据来源及结论。请用列表形式展示每篇文献的图表信息，并总
结其数据的关键意义。
文献引用率与影响力分析指令： 
 用途：用于分析文献的引用次数和学术影响力。 
 指令： 
 请对之前推荐的【数字】篇文献的引用率和影响力进行分析，按照每篇文献的引用次数、
H 指数及影响因子进行排序，并给出分析结论。这将有助于我了解哪些文献在该领域中具有
较高的学术影响力。
```


## 使用建议

- 将上方提示词完整复制后发给 AI 即可使用。
- 如提示词中含 [ ] 占位或示例，替换为你自己的内容。
- 若输出不满意，补充风格、长度、平台等偏好让其迭代优化。
