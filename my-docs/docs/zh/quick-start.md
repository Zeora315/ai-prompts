# 快速上手

欢迎使用 **AI 提示词集**！这里汇总了精选的 AI 提示词，按「工作与效率 / 内容创作 / 学术与专业 / 其他」分类，帮你更高效地驱动 AI。

## 三步使用一条提示词

1. **复制**：进入对应分类，点击提示词代码块右上角的复制按钮。
2. **替换占位符**：将文中的 `{{...}}`（如 `{{会议记录}}`、`{{主题}}`）替换为你的真实内容。
3. **粘贴发送**：把填好的提示词粘贴到任意 AI 对话工具（如 ChatGPT、Claude、通义千问等），发送即可。

:::tip
占位符 `{{...}}` 只是示意，你可以保留、删除或改写它们，按自己的需要自由调整措辞与要求。
:::

## 使用技巧

- **明确角色与输出格式**：提示词里已默认指定角色（如「资深执行官助理」）和格式（列表 / 表格），效果通常更好。
- **追加约束**：在提示词末尾补充要求，例如「用表格输出」「控制在 100 字以内」「面向小白解释」。
- **多轮迭代**：第一版不满意时，让 AI「换一种风格再写一版」或「更专业一些」，逐步逼近理想结果。
- **保存常用组合**：把高频提示词收藏到自己的笔记，形成个人提示词库。
