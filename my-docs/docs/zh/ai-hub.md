## 11. 使用Tips：搭配本站提示词增效方案
1. **长文档场景（论文/财报/合同）**
   推荐工具：Kimi / Claude / 智谱清言
   配套提示词：「论文 Kimchat 指令模型手册」「合同深度风险审查指令」
2. **日常办公写作（周报/方案/短视频脚本）**
   推荐工具：豆包 / 通义千问 / 火山写作
   配套提示词：「周报编写助手」「短视频爆款脚本生成指令」
3. **代码开发**
   推荐工具：Cursor / Trae / DeepSeek
   配套提示词：「全栈项目重构指令」「Bug定位修复专用提示词」
4. **图像视频创作**
   推荐工具：Midjourney / 可灵 / 即梦
   配套提示词：「国风插画标准提示词模板」「电影级视频运镜指令」
5. **学术研究**
   推荐工具：Gemini / Perplexity / 星火科研助手
   配套提示词：「文献综述自动梳理指令」「实验数据分析模板」
